# Changelogs

## 1.1.0

- Added official manifest fields: `readme`, `files`, `changelogs`, and root `icon.png`.
- Improved `.beta` icon handling for Acode file tree and active tab.
- Added compatibility with `acode.setPluginInit` and `acode.setPluginUnmount`.
- Kept GitHub plugin source URL support for global install.

## 1.0.2

- Added lowercase `readme.md` so Acode can load plugin documentation.

## 1.0.1

- Added BetaScript icon assets.
- Added `.beta` file recognition fallback.
